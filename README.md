# Nhom2_TKCSDL
## Cấu trúc thư mục

```
.
├── main.tex          # File chính: preamble + gộp các chương
├── chapters/         # Mỗi chương/phần là một file .tex riêng
│   ├── 00_frontmatter.tex
│   ├── 01_mo_dau.tex
│   ├── 02_chuong_1_tong_quan_va_quy_trinh_thiet_ke.tex
│   ├── 03_chuong_2_thiet_ke_quan_niem_erd_eer.tex
│   ├── 04_chuong_3_thiet_ke_logic_phu_thuoc_ham_va_chuan_hoa.tex
│   ├── 05_chuong_4_thiet_ke_vat_ly.tex
│   ├── 06_chuong_5_ket_luan_va_huong_phat_trien.tex
│   ├── 07_tai_lieu_tham_khao.tex
│   ├── 08_phu_luc_a_script_t_sql_tao_co_so_du_lieu_familyconnectdb.tex
│   └── 09_phu_luc_b_bang_tong_hop_quan_he_thuoc_tinh_dien_giai_kieu_du_lieu.tex
└── images/           # Hình ERD trích từ file Word gốc
    ├── image1.png
    └── image2.png
```

Ngoài ra còn có thư mục `fonts/` chứa các file font `.otf` (TeX Gyre Termes,
TeX Gyre Cursor) được nạp trực tiếp, giúp việc biên dịch không phụ thuộc vào
font cài sẵn trên máy — xem mục "Font chữ" bên dưới.
