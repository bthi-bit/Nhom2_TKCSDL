\phantomsection
\addcontentsline{toc}{section}{5.1. Kết quả đạt được}
{\Large\bfseries 5.1. Kết quả đạt được}\par\vspace{0.7em}

\begin{itemize}
\item Áp dụng đầy đủ chu kỳ sống CSDL (Chương 1) để tổ chức toàn bộ quy trình thiết kế FamilyConnect.
\item Xây dựng mô hình ERD theo ký pháp Chen cho nhóm lõi, xác định đúng thực thể/thuộc tính/mối kết hợp/bản số, nhận diện 2 thực thể yếu và 1 trường hợp phụ thuộc tồn tại dễ nhầm với thực thể yếu, đồng thời phân tích chiến lược ánh xạ EER cho vai trò người dùng (Chương 2).
\item Chứng minh bằng lý thuyết phụ thuộc hàm (bao đóng, tìm khóa, phân rã 2NF→3NF, kiểm tra BCNF và bảo toàn kết nối) rằng lược đồ quan hệ nhóm Sự kiện — và suy rộng ra toàn hệ thống 33 quan hệ — đều đạt chuẩn BCNF (Chương 3).
\item Triển khai vật lý hoàn chỉnh bằng T-SQL trên SQL Server 2022 (Docker), có đầy đủ ràng buộc CHECK, khóa ngoại, chính sách xóa/cập nhật và chỉ mục (Chương 1 + Chương 4 đồ án).
\end{itemize}

\phantomsection
\addcontentsline{toc}{section}{5.2. Hạn chế}
{\Large\bfseries 5.2. Hạn chế}\par\vspace{0.7em}

\begin{itemize}
\item SQL Server chưa hỗ trợ kiểu vector gốc như PostgreSQL/pgvector; tính năng tìm kiếm ngữ nghĩa AI cần tích hợp thêm dịch vụ vector store ngoài (Azure AI Search, hoặc SQL Server 2025 có DiskANN) để đạt hiệu năng ANN tốt ở quy mô lớn.
\item Ràng buộc nghiệp vụ 'mỗi thành viên có tối đa hai cha/mẹ sinh học' chưa biểu diễn được bằng khóa/khóa ngoại thuần túy, cần trigger hoặc kiểm tra ở tầng ứng dụng.
\item Dashboard thống kê hiện dùng bảng Reports lưu kết quả đã sinh; nên bổ sung Indexed View hoặc bảng tổng hợp định kỳ để tối ưu hiệu năng truy vấn lớn.
\end{itemize}

\phantomsection
\addcontentsline{toc}{section}{5.3. Hướng phát triển}
{\Large\bfseries 5.3. Hướng phát triển}\par\vspace{0.7em}

\begin{itemize}
\item Viết trigger kiểm tra ràng buộc phả hệ phức tạp (giới hạn số cha/mẹ, phát hiện vòng lặp quan hệ huyết thống).
\item Bổ sung Change Data Capture (CDC) hoặc Temporal Tables của SQL Server để lưu lịch sử thay đổi gia phả theo thời gian.
\item Đánh giá chuyển một phần dữ liệu AI Embedding sang giải pháp vector store chuyên dụng khi số lượng bản ghi lớn.
\end{itemize}
